EXECUTIVE SUMMARY

Personal AI assistants are more useful when they remember their user, but most send every conversation to a company's servers and let the language model itself decide what to remember. This project designed, built and evaluated PIP (Personal Intelligence Platform), a Windows desktop assistant that runs its language model on the user's own computer and keeps each profile's chats, memory, documents and decisions in a database encrypted with a key derived from the profile's password. In PIP the model only proposes what it has learned; fixed rules decide. Each proposed fact must be quoted from the conversation, supported by the user's own words and allowed by a written Constitution, sensitive facts wait for the user's confirmation, and every decision is recorded in an append-only audit log. Nothing leaves the computer without the user's recorded consent. PIP was built with Flutter, Python, FastAPI, SQLCipher, ChromaDB and Ollama, and its guarantees were written as nine promises, each with a test seen to fail when its mechanism was weakened; 1,889 backend and 372 app tests pass. In evaluation PIP stored none of 237 trick statements, but it learned few true facts from long conversations, and a blind check found that 8 of 58 quotes its evidence check accepted did not support their claim. Fixing a defect found by measurement cut the time to an answer's first word from 4.48 to 0.36 seconds. The project shows that an assistant's memory can be governed by auditable rules, at a cost in what it learns.
